概述
EditorOnlyMetadata 标记编辑器专用字段；ShowEditorOnlyMetadata 在引用字段下显示被引用对象上的标记字段。


用法
元数据字段放在 UNITY_EDITOR 条件编译块中，并符合 Unity 序列化规则。在引用字段上添加 ShowEditorOnlyMetadata。


示例
#if UNITY_EDITOR
[SerializeField, EditorOnlyMetadata, TextArea]
private string description;
#endif

#if UNITY_EDITOR
[ShowEditorOnlyMetadata]
#endif
public AttributeSO Attribute; // 在此引用下显示 AttributeSO 的元数据

// 普通字段标签与内容同行；TextArea 标签在上方，内容占整行。
// 显示使用临时 SerializedObject，输入不会写回资源，重绘后恢复原值。


推荐场景
在配置列表或对象引用旁查看资源备注等编辑器专用信息。
